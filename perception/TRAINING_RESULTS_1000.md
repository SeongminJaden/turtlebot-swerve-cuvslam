> 정정: 후속 라벨 감사에서 data-v5의 일부 AprilTag bbox가 여러 물체를 잘못 포함하는 오류를 발견했다. 이 문서의 YOLO 수치는 잘못된 정답을 사용한 과거 결과이며 성능 승인 근거로 사용할 수 없다. 텍스처 표면과 픽셀 마스크로 라벨을 다시 만든 data-v8-clean 결과로 대체한다.

# 1,000장 학습 결과 — 2026-10-30

YOLO와 CenterPose 각 20 epoch 학습 및 별도 시험 이미지 100장 평가를 완료했다.
Isaac Sim GUI와 별도 GTK 학습 모니터를 켠 상태로 수행했다.

## 데이터

- 학습 800장 / 검증 100장 / 시험 100장. 시드 분리, 시험 자료로 checkpoint 선택하지 않음.
- 빨강·초록 원기둥/직육면체, 박스, AprilTag의 6개 검출 클래스.
- 모든 퍽 footprint가 박스 윗면 내부, 퍽끼리 보수적 충돌 경계 비중첩 검사 통과.
- 박스·퍽 위치와 yaw 랜덤. 직육면체 6개 바닥 접촉 면 모두 포함.
- 실제 표식 ID0..11 퍽(16mm/여백포함20mm), ID12..14 장소(48mm/60mm).
- 물품의 여러 면은 동일 ID. 직육면체 6면, 원기둥 위/아래/곡면1곳.
- 중앙 장소 태그와 퍽에 의한 가림 포함. 25%는 중앙 장소 태그 없는 박스.
- 박스는 밤부랩 개별 필라멘트 상자의 갈색 단순 모델. 실제 인쇄와 치수 미확인.

## YOLO 시험 결과

| 지표 | 결과 |
|---|---:|
| Precision | 0.9699 |
| Recall | 0.9484 |
| mAP50 | 0.9478 |
| mAP50-95 | 0.9208 |

AprilTag 클래스 AP50은 0.7120로 퍽/박스보다 낮다.
2픽셀 수준의 작거나 거의 가려진 태그도 포함돼 있다. AP는 태그 ID 디코딩률이 아니다.
합성 근접 작업대 조건의 성능이며 실물/미로 배경 성능이 아니다.

## CenterPose 시험 결과 — 제어 사용 불가

정답 bbox와 알려진 치수를 사용한 단독 평가다. YOLO 오차도 들어가지 않은 조건에서
이미 자세 오차가 크므로 현재 체크포인트를 집기 제어에 연결하지 않는다.

- 평가 객체: 459개.
- 재투영·confidence 필터를 통과한 PnP 후보: 241개 (52.5%).
  이 필터 통과는 실제 자세 정확도를 뜻하지 않는다.
- 필터 통과 후보의 위치 오차 중앙값: **1371.3mm**.
- 순서 고정 모서리 평균 오차: 91.25px.

20 epoch로 학습 실행은 완료했지만 모델 품질은 실패다. 반복 ID와 대칭 형상의
회전/면 모호성, 랜덤 초기화, 부분 가림의 crop 학습 영향을 다음 수정에서 분리해
확인해야 한다. 원인 하나로 단정하지 않는다. 보이는 평면 태그의 기하 기반 위치
추정과 깊이를 기준선으로 비교하고, CenterPose는 대칭을 고려한 손실과 데이터 필터,
초기 가중치를 검토해야 한다. 후속 모델을 선택할 때 이번 시험 세트에 맞춰 튜닝한
결과를 독립 시험 성능으로 재사용하지 않는다.
