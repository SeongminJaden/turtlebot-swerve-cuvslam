# 개발 기록

## 2026-10-26: 기반 구현과 강의 실습 01

### 시작 상태

`ff09d94`에는 CAD136 기반 모델, 스테레오 USD, 렌더 시험 스크립트와 cuVSLAM launch 초안이 있었습니다. ROS 제어 패키지나 스워브 역기구학은 없었습니다.

### 구현

`4f0f992`에서 URDF 축 기반 역기구학, 공통 속도 포화, 정지 때 조향 유지, ROS 입력/출력과 watchdog을 추가했습니다. 단위 테스트 5개가 모듈별 접촉 속도를 몸체 명령으로 다시 복원해 검증합니다.

모델 축 차이를 발견했습니다. 앞 두 wheel joint는 +X, 뒤 왼쪽은 +Y, 뒤 오른쪽은 -Y입니다. 이를 같은 축으로 가정하면 직진 명령에서도 바퀴 방향이 달라집니다.

ROS 통신 검사에서는 합성 측정 피드백을 사용합니다. 피드백 부재, 정렬 후 구동, 명령 만료, 피드백 만료를 구분해서 확인합니다. 이 결과는 물리 주행 검증이 아닙니다.

### 실행 중 해결한 문제

- package.xml의 localhost 이메일을 catkin_pkg가 거부해 colcon이 일반 Python 패키지로 분류했습니다. 유효한 예시 이메일로 수정하자 ros.ament_python으로 인식하고 ament index 경로가 생성됐습니다. 배포 전 maintainer 이메일을 실제 관리 주소로 교체해야 합니다.
- 저장소의 Git 작성자 설정이 비어 있었습니다. 전역 사용자 설정을 변경하지 않고 각 자동 커밋에 Codex 작성자를 지정했습니다.
- 기존 Sim 환경에서 스테레오 이미지와 모델 전체 렌더를 얻었습니다. 모델 연속 캡처는 완료되지 않았고, 재실행 때 기존 venv가 삭제된 것을 발견했습니다. 사용자 요청으로 버전 고정 재설치를 시작했습니다.
- 공식 Sim 6.1 문서상 Lyrical은 권장 bridge 배포판이 아닙니다. 현재 제어 노드의 Lyrical 검사와 향후 Sim bridge 검증을 구분했습니다.

### 강의자료

`6ef3aba`에서 모듈6 원본의 검은 표지, 흰 본문, KANT 표기, 글꼴 및 슬라이드 크기를 유지한 17장 실습자료를 만들었습니다. 원본 37~45강을 덮어쓰지 않았습니다. Git 명령, 파일 구조, 수식, 코드 작성, 실행 및 실패 분석을 LAB_GUIDE와 판서가이드에 담았습니다.
