# 검증 상태와 실행 순서

현재 통과 결과는 `checks/model_validation.json`의 **정적 검사 항목만**이다.
구형 Sim 5.1 / Lab 2.3.2 참고 실행 결과는 요청 버전과 다르므로 이 저장소 합격 증거에 포함하지 않았다.
Sim 6.1 로컬 시도는 EULA 미동의로 실행되지 않았고, 사용자가 Ubuntu용 저장소 준비로 범위를 변경했다.

1. 정적 모델 검사를 실행해 누락 메시, 다중 parent, cycle, USD unresolved asset, 카메라 위치·축·기준선을 확인한다.
2. Ubuntu Sim 6.1에서 스테레오 렌더링 스크립트를 실행하고 두 영상의 크기·시차·시야를 육안 확인한다.
3. 13관절 모델을 물리 실행하고 NaN/발산, 조향 방향, 바퀴 회전, 팔 관절을 확인한다. 현재 렌더링 스크립트는 물리 구동 검사가 아니다.
4. ROS 5.0에서 Image/CameraInfo/clock/TF를 확인하고 launch를 실행한다.
5. 정지·직진·좌우 이동·제자리 회전·폐곡선 경로를 시험한다. 추적 초기화 시간, tracking loss, ATE/RPE, 처리시간을 기록한다. timestamp 정렬과 좌표 변환을 먼저 검증한다.
6. Lab EA에서 1환경 로드 → 제어 action/observation → reset → episode 종료 → 작은 학습 순으로 진행한다.

전체 시스템 PASS를 기록하려면 위 실행 로그와 버전, GPU, 테스트 조건을 함께 저장해야 한다.
임시 카메라·질량·충돌·관절 한계를 실물 기준으로 바꾸기 전에는 sim-to-real 사용을 승인하지 않는다.
