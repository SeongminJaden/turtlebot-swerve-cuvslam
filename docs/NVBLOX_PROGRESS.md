# nvblox / Nav2 확장 진행 상태

2026-10-27 작업 스냅샷. 기존 두 지정 미로 경로 검증과 새 Nav2 통합 검증은 구분한다.

- nvblox 5.0 공식 바이너리 GPU 시작 및 깊이 적분 확인.
- Nav2 planner_server + NvbloxCostmapLayer 연결, 1초 주기 재계획.
- map 경로를 5 cm 간격으로 변환하여 기존 24차원 PPO 관측에 연결.
- 경로 2.5초 / nvblox slice 1초 지연 시 주행 차단.
- 첫 통합 GUI 실행: 경로 20회 갱신, 33.735초에 차체 접촉으로 중단. 완주 검증 실패.
- 후속 조정: 반경 0.315 m, inflation 0.42 m, cost scaling 5.0, NavFn Dijkstra, 전방 추종점 0.10 m. 90초 시험에서 유효 경로가 생성되지 않아 실패.
- 스워브 코너 속도 최적화는 미완료. 접촉 없는 경로·추종 검증 이후 속도 비교 필요.
- 전체 Python 테스트 70개 통과. 단위 검사 통과가 폐루프 주행 성공을 의미하지 않음.

## 실행

```bash
python3 scripts/setup_nvblox_runtime.py
GUI=1 USE_NVBLOX=1 DURATION=180 bash scripts/run_predictive_async.sh evidence/nvblox-run
```

기존 로컬 robot_localization 런타임과 Sim/Lab 설치가 필요하다. 최초 RTX 셰이더 컴파일은 100초 이상 소요될 수 있다.

## 좌표 변환·해상도 보완 및 다음 검증

- 공식 NvbloxCostmapLayer 소스의 TF 조회 실패 후 갱신 동작과 실행 로그의 미래 시각 TF 오류를 확인했다.
- `scripts/nvblox_map_slice.py`는 해당 영상 지도 시각의 map 변환을 기다린 뒤 `/navigation/map_slice`로 재투영한다. 변환이 없거나 0.5초를 넘긴 지도는 발행하지 않는다. 미관측 셀은 미관측으로 유지한다.
- 2.5 cm 복셀 + 위 변환 보완만 적용한 90초 시험: 경로 생성 실패, 비바퀴 접촉 0 N, 실시간 배율 약 1.00. 수정만으로 완주 문제가 해결되지 않았다.
- 복셀을 1.25 cm로 줄인 시험에서 첫 코너까지 주행했지만 이후 경로 생성 실패가 발생했다. 로봇 반경 0.315 m는 유지했다. 최종 통과로 보지 않는다.
- 차체 초기 방향 기본값을 0도로 변경하고, 고정 -45도 유지 대신 경로 접선 방향을 추종하도록 수정했다. 직선 구간에서는 추정 정렬 오차 5도 이내에서만 병진 명령을 허용한다. 실제 차체 정렬·접촉은 별도 시뮬레이션 평가가 필요하다.
- 영상마다 유효 깊이 비율, 전방 하단 유효 깊이 비율, 텍스처 분포, 과다·과소 노출 비율, 라플라시안 분산을 기록한다. 이는 카메라 정책 확장을 위한 관측 자료이며, cuVSLAM 성공률이나 재학습 완료를 뜻하지 않는다.

## 카메라 정책 확장 요구사항

현재 배포 체크포인트는 가감속과 팔 yaw 속도만 출력한다. 팔 높이·pitch 최적화는 아직 학습하지 않았다. 다음 학습에서는 실제 관절 제한과 충돌 검사를 적용한 팔 자세 제어를 추가하고, 경로 진척도와 영상·깊이 관측 품질을 함께 평가한다. 정지 상태에서 좋은 영상만 유지하는 정책을 방지하기 위해 완주 시간·정지 시간·동시 주행/팔 동작 비율을 함께 비교한다. 영상 품질 대리 지표만으로 보상을 구성하지 않고 실제 추적 상태, 위치 오차, 접촉 결과를 분리해서 검증한다.


직선 정렬 v8 시험은 89.96초, 최대 속도 0.423 m/s, 비바퀴 접촉 0 N으로 종료했으나 목표 오차 2.607 m로 완주에 실패했다. 첫 직선의 정렬은 확인했지만 전체 경로 기준 검증은 남아 있다. v6은 초기 차체/AMCL 방향 불일치로 중단했고, v7은 Lab 시작 중 네이티브 크래시로 주행 평가에 사용하지 않았다.

재계획 시 짧아진 경로의 인덱스를 진행률로 쓰면 PPO 관측이 매초 출발점으로 돌아간다. 최초 계획 길이와 현재 남은 호 길이를 사용하도록 보완했다. 스워브에서는 기존 제동-조향 단계 대신 연속 조향 옵션을 추가했으며, 조향 속도·바퀴 가감속·정렬 오차에 따른 구동력 제한은 유지한다. 이 옵션은 실제 접촉 및 완주 평가를 통과하기 전까지 실험 설정이다.


연속 조향 v10 시험: 99.97초, 최대 속도 0.365 m/s, 비바퀴 접촉 0 N, 목표 오차 2.577 m로 시간 초과. 완주와 속도 향상은 아직 확인되지 않았다. 이후 영상 누락 시 내부 속도 상태를 즉시 0으로 만드는 대신 감속 제한에 따라 감소시키는 변경을 추가했으며, 이 변경의 폐루프 검증은 아직 수행하지 않았다.

추가 사용 가능 센서: LDS-03 4대, RealSense D435 2대(사용자 확인). 다음 설계에서는 고정 센서로 주행 관측을 확보하고, 팔 카메라의 가동을 필수 주행 조건에서 분리하는 구성을 우선 비교한다. D435 장착 위치·동기화와 라이다의 가림 영역은 아직 실물 계측하지 않았다.
