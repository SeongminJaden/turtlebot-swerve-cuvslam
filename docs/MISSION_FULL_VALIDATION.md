## 집기가 막히는 근거

원본 arm_joint2~5 범위는 ±0.35rad이다. URDF FK와 USD의 arm_link5 전체
형상을 포함하는 AABB를 사용했다. 차체가 수평이고 base Z=0인 조건에서,
모든 허용 관절 자세에 대한 보수적 최저 높이 하한은 **185.65mm**이다.
이는 실제 최저점의 추정치가 아니라, 이보다 아래로 갈 수 없다는 하한이다.
퍽은 바닥 70mm, 윗면 130mm이므로 하한만으로도 접촉 불가를 판정할 수 있다.

별도로 수치 최적화한 AABB 최저 높이는 213.05mm이다. 그 자세를 PhysX
관절 드라이브에 명령했고 실제 엔코더값이 목표 ±0.02rad 안에 들어왔으며,
세계 좌표에서 AABB 최저점은 약 211.85mm였다. 차체의 정착 높이 때문에
FK의 base Z=0 결과와 약간 다르다. 이 값은 그리퍼 TCP의 도달점이 아니며,
전체 끝 링크 형상의 보수적인 경계값이다. 원본 충돌 프록시·자기충돌
필터링 한계는 유지된다.

## 센서 시험 조건

- 원본 R12의 첫 번째 상단 카메라, 1280×960.
- 바코드 중심은 PDF의 (80,650,450)mm. 패널 크기 320×160mm는 시뮬레이션 가정.
- 바닥에 선 신호등, 발광부 중심 (83,950,650)mm, 100×100mm.
  실물 치수가 제공되지 않아 만든 단일 색상 표시 패널이며 실물 광학 검증이 아니다.
- 카메라 영상에서 빨간 영역을 찾아 고정 ROI를 얻고, 이후 프레임의 HSV로
  R/Y/G/OFF를 판정한다. 정답 시퀀스를 분류기에 전달하지 않는다.
- 1초 점등/1초 소등, 마지막 3초 소등. 4Hz 샘플링, 총 109개 실제 렌더링 프레임.
- `SignalRecorder`에는 영상 판정값과 실제 World 시계가 들어간다.
  정지 로봇 시험이며 ROS 브리지·이동 중 추적 시험은 아니다.
- 원본 퍽 ID/모양 표가 제공되지 않아 합성 목록을 쓴다. 현 단계의 전체 할당은
  등록 목록 기반이며 카메라 퍽 인식 완료를 의미하지 않는다.

## 재현

```bash
python3 scripts/prepare_mission_assets.py
python3 -m unittest discover -s tests -v
OMNI_KIT_ACCEPT_EULA=YES /home/seongmin/isaacsim6_venv/bin/python scripts/mission_headless.py --full-audit --output evidence/2026-10-30/full-mission-v4
```

`--full-audit`는 현재 **종료코드 1**이 정상적인 검증 결과다. 일부 단계의
통과가 전체 완주로 잘못 표시되지 않게 한다. report.json의
`mission_complete=false`와 mission-audit/audit.json의 실패 근거를 확인한다.

신규 `mission_verification.py`는 2초 신선한 관측, ID 중복/누락,
10mm 위치 오차와 복귀 시 차체 전체 포함/3초 정지를 검사한다. 프레임의
실제 카메라 유래 여부는 상위 어댑터가 보장해야 하며, 검사기 단위 시험에
사용한 합성 기록은 경기 수행 증거가 아니다. 전체 unittest 45개 통과.

## 완주 개발에 필요한 결정

원본을 유지하면 결과는 도달성 실패다. 별도 시뮬레이션용 모델을 허용하면
팔 관절 범위, 그리퍼 가동부/충돌체/구동축을 명시적으로 추가하고,
자기충돌·팔-차체 간섭·잡기·놓기를 먼저 검증해야 한다. 그 모델에서의
완주를 원본 R12 또는 실기 완주로 보고하지 않는다.
